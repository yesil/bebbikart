# BebbiKart game (Godot 4)

The kiosk game: toy-world course, 60 Hz driving sim, weather, and a mock network so everything runs without the server.

## Run

From `apps/game`:

```sh
godot --headless --import                     # first time / after pulling
godot --path .                                # windowed, mock mode (default; no server client yet)
godot --headless --path . -- --duration=40 --speed=8 --seed=5 --log=summary
godot --headless --script res://tools/sweep.gd -- --builds=60 --seeds=2
```

Game flags (after `--`):

| Flag | Meaning |
|---|---|
| `--mock` | Mock network. This is the default; `--server` only prints a warning for now. |
| `--racers=N` | Number of fake players (default 20) |
| `--seed=N` | RNG seed for mock players and weather |
| `--weather=calm\|rain\|wind\|storm` | Force the weather (default: the state machine) |
| `--speed=X` | Sim speed multiplier (raises the physics tick rate) |
| `--duration=SEC` | Quit after SEC wall seconds and print a summary |
| `--log=none\|summary\|full` | What outgoing messages to print |
| `--screenshot=PATH [--shot-at=SEC] [--cam=follow\|wide\|forks]` | Save a screenshot (windowed only) |

Keys:

| Key | Action |
|---|---|
| C | Camera mode (follow / wide / forks) |
| Tab | Next racer |
| F | Fork shot |
| B | Boost the followed racer |
| R / W | Advance the rain / wind phase |
| K | Toggle forced calm |
| H | Hide the overlay |

Sweep flags:

| Flag | Meaning |
|---|---|
| `--builds=N --seeds=N` | Number of random builds and seeds per build |
| `--quick` | Short run |
| `--boost=perfect\|none` | Boost behaviour |
| `--json=PATH` | Dump results as JSON |
| `--trace=PATH` | Write a trace |

## Layout

- `sim/`: the simulation. Plain `RefCounted` GDScript with no scene nodes, so it runs headless in the sweep.
  - `tuning.gd`: every constant.
  - `route.gd`, `course.gd`: the course and all fork variants, with section lines, boost zones and widths.
  - `weather.gd`: the weather state machine.
  - `builds.gd`: stars → stats, plus random builds.
  - `racer.gd`: racer state (s/d/v/vy), autopilot, fails, boost, events, splits and traces, timed in sim ticks.
  - `sim.gd`: the fixed step, the start queue (4 lanes), collisions and the outbox.
- `net/`:
  - `protocol.gd`: generated by WS1. Do not edit.
  - `messages.gd`: envelope helpers.
  - `mock_net.gd`: the fake server and phones. It spawns players with random builds, routes and styles, launches runs, taps boosts (skilled players tap inside zones) and logs the `game.run.*` messages it would send.
- `world/`:
  - `world_builder.gd`: the procedural grey-box toy world.
  - `racer_view.gd`: placeholder racers.
  - `weather_fx.gd`: rain, wind and storm visuals.
  - `camera_rig.gd`: simple follow, wide and fork cameras.
- `main.gd` / `main.tscn`: wires net → sim → views and draws the debug overlay.
- `tools/sweep.gd`: the headless balance sweep.

## Balance snapshot

Results from `sweep --builds=60 --seeds=2`, solo racers with perfect boosts.

**Default build** (balanced style, around/bridge/sheltered):

| Weather | Time |
|---|---|
| calm | 32.2 s |
| rain | 37.0 s |
| wind | 35.1 s |
| storm | 40.5 s |

**Driving style, calm:** careful 35.1 s, balanced 32.2 s, daring 29.7 s.

**Random builds:**

| Weather | Median | Best–worst | Fail rate |
|---|---|---|---|
| calm | 31.9 s | 27.9–39.1 s | 0% |
| rain | 36.6 s | — | 0.8% |
| wind | 35.9 s | — | 3.3% |
| storm | 40.0 s | — | 11.7% |

**Forks:**
- **Ramp:** jumping is worse at jump 0–3 (+0.4–0.9 s) and better at jump 4–5 (about −1 s).
- **Pond:** water wins from water 1 star upward (−0.4 to −3.7 s calm), and wins by more in rain and storm.
- **Crossing:** the exposed route is about 1.8 s faster in calm. In wind, sheltered wins at stability 0.

## Known issues and deviations

- There is no real WebSocket client yet; only the mock runs.
- Racers are placeholder shapes. The racer kit (3d) and the HUD and camera director (3c) are separate sub-streams.
- `splitMs` is the time spent in each section.
- Wind direction is `(cos dirDeg, 0, sin dirDeg)` in world XZ.
- Crowded storms fail often: about 30% in the sweep. In mock mode the fail rate is about 13% in calm and about 25% in rain, mostly `off_track` in bends from collisions and daring slips.
